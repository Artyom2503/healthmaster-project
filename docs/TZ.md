# Техническое задание: AI-коуч по питанию

## Задача

Улучшить AI-коуча по питанию на базе GPT-4o для повышения вовлечения пользователей.

## Проблема

Текущие метрики:
- Адопшн новых пользователей: 18% (цель ≥50%)
- Return Rate: 17% (цель ≥45%)
- One-and-done: 83% (цель <50%)
- Качество ответов: 93% (хорошо)

Проблема не в качестве ответов, а во вовлечении и удержании.

## Цели проекта

1. Увеличить Return Rate с 17% до 45%+
2. Снизить One-and-done с 83% до 50%
3. Повысить адопшн с 18% до 50%+

## Входные данные

- Текущий промпт коуча
- Метрики из coach_analytics_service
- Диалоги пользователей
- Настройки GPT-4o

## Ожидаемый результат

- Улучшенный промпт с durable-памятью
- Персональные триггеры
- Метрики стикинесса
- A/B фреймворк

## Сроки

- Базовый набор улучшений: 3-5 дней
- Замер метрик: через неделю
